How to use this site

  • Journal — the latest entry, and the archive by month.
  • Playbook — every practical takeaway, filterable by theme. The fastest way to act on what the journal has learned.
  • Concepts — the ideas behind the news, explained in plain language.
  • Watching — what each entry said to watch next, and which later entries followed up.
  • Review — flashcards built from the takeaways, concepts and self-tests, for spaced repetition.
  • Weekly digest — one page per week when daily is too much.
  • Tokenizer, Tokenomics and the Model Team Evaluator — tools for the cost side of agents.
  • RSS and llms.txt for readers and machines.
