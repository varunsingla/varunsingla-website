Takeaways of the week

  • Allow-list, don't deny-list. Define exactly which tools, sites and actions an agent may use; treat everything else as forbidden. Day 203
  • Gate write actions. Reading is low risk; submitting forms, sending email or paying should need human approval. Day 203
  • Try interactive answers. Ask ChatGPT a number-heavy question and see whether Intelligent UI beats plain text; then verify the figures it shows. Day 202
  • Separate run rate from revenue. When you read a company's annualized figure, ask how it is measured and what is committed in spending. Day 202
  • Put limits on your agents. Set request-rate caps, write permissions and an audit log before letting an agent touch any external service. Day 201
  • Identify your bots. Use a descriptive user-agent, respect robots.txt and rate limits, and prefer official data dumps. Day 201
  • Wait for weights, then test. Do not plan around Beam's numbers; when weights ship, run your own ten-task evaluation against your current model. Day 200
  • Build a private eval set. Collect 10-20 real tasks with known good answers; reuse it for every new model announcement. Day 200
  • Re-test your default model. Run ten real tasks on Opus 5.5 at medium effort versus your current model; compare quality and cost, not leaderboards. Day 199
  • Use the effort dial. Default to medium, raise it only for hard tasks, and keep stable prompt prefixes first so cache discounts apply. Day 199
  • Re-benchmark your default model. Run your own ten real tasks on GPT-6.1 Sol versus your current model and compare quality and cost, not leaderboard scores. Day 198
  • Exploit caching. Keep the stable part of an agent's prompt identical and at the front so cached-input discounts apply. Day 198
  • Enforce rules outside the prompt. Put permissions in tool and policy layers that block disallowed actions, rather than only instructing the model. Day 197
  • Grant least privilege. Give an agent only the folders, accounts and tools a task needs, with no blanket disk or inbox access. Day 197
